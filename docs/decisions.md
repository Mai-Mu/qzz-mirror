## 行为细化

- 将同一物理设备的 USB / Wi-Fi 连接尽可能归为同一个设备，操作必须指向选中设备及明确的传输通道。
- 自动恢复仅尝试已知、已配置或已配对的同一设备无线连接。失败后停止自动循环，等待用户操作。
- 所有开始操作明确传入 scrcpy 设备标识，避免直接启动时出现“多个 ADB 设备”歧义。
- 启动外部程序使用参数数组，不将设备地址、配对码或路径拼接为 shell 命令。
- 投屏会话和应用状态以真实执行结果更新；浏览器设计预览中的演示数据不得作为真实连接结果。
- “最高”对应 `maxFps: null`，不传 `--max-fps`；手动值按整数校验并原样作为上限。所有启动固定 `--max-size 0`，码率在后端固定为 `8M`，不提供设置项。
- 从 0.1.0 读取配置时忽略旧 `preset`，新帧率默认为“最高”，保留声音、置顶、连接偏好、上次设备和已保存无线地址。

## 旧版差异

0.1.0 曾提供“流畅 / 均衡 / 清晰”预设，并使用较大的主页窗口。0.2.0 已取消这些预设，将可调整项收进设置页。旧版真机记录保留在验收文档中，不视为新版通过。

## 验收边界

版本记录与文件校验由构建脚本产生。真机连接、无线配对和自动恢复必须使用对应条件的设备验证；没有可用硬件时保留待验证状态，不能用编译通过代替。具体条件见 [验收清单](acceptance.md)。

## 0.2.1 图标调整（2026-10-29）

- 品牌标识采用蓝色圆角底与手机、屏幕线框，减少细碎交叠。

## 0.3.0 三键栏边界

- 使用应用自有的 Win32 窗口，不获取输入焦点（`NOACTIVATE`），不改 scrcpy 窗口位置、大小及快捷键。
- 普通窗口时贴在投屏窗口底边外侧，跟随移动、缩放、最小化及关闭；仅跟踪本应用拥有的当前投屏窗口。
- 全屏或底部空间不足时收起，鼠标进入可见画面底边 6 DIP 时唤出短暂浮层；离开触发边缘与按键栏 350 毫秒后隐藏。
- 最近任务、返回、主页分别发送固定 Android 按键码 `187 / 4 / 3`；只向当前 `Running` 会话的 token 与 serial 发送。
- 停止、恢复连接期间及旧 token 请求一律拒绝，不能转发给新会话或其他设备；失败沿用现有日志反馈。
- 后端隔离测试通过不等于原生窗口、鼠标交互或真机通过；对应验证结果单独记录。

## 0.3.1 延迟与绘制修复

- 三键栏复用已运行 scrcpy 的左 Alt+s/b/h 快捷键通道，不能在每次点击时创建新的 ADB / Android input 进程；Windows 使用 SYSKEY 消息，避免普通 WM_CHAR 混入输入。
- 单纯移动只调整底栏坐标；尺寸或 DPI 变化时才重新布局，不重复设置未改变的启用状态。
- 绘制采用缓冲，避免绘制重入被跳过或背景先显示、图形后显示。
- 发送前仍验证当前就绪会话与自有进程，不抢前台或修改全局键鼠状态。
- 当前物理修饰键或目标字母仍按下时拒绝投递；部分消息投递失败只对原窗口尝试补发释放消息，不向替代窗口清理。此清理为尽力行为，不能保证窗口异常时仍全部完成。
- 本地投递耗时与手机画面端到端响应分别记录，不能将前者当作后者的实测结果。
