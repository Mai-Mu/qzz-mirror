# Qzz Mirror · 轻镜 v0.2.1

这是项目的首次 GitHub 发布。0.1.0、0.2.0 仅为本地历史版本，本说明按本地记录区分各次变化。

## 本次更新：相对本地 0.2.0

- 更新品牌标识，使用蓝色圆角底与手机、屏幕线框，小尺寸下更清楚。
- 统一标题栏、应用、托盘与网站图标。
- 重绘设置齿轮，调整中心、齿距与描边。
- 首次公开发布附带更新日志与第三方许可文档，下载包清单不包含开发机路径。

连接与投屏功能沿用 0.2.0，内置 scrcpy 5.0.1。

## 从本地 0.1.0 升级

- 更紧凑的控制面板：默认 840 × 560，最小 720 × 480。
- 主页专注设备与投屏；通过齿轮进入内部设置页。
- 使用设备原始分辨率，取消三档画质预设。
- 帧率默认“最高”，也可通过滑块或数字输入设置 1～240 FPS 上限。
- 声音和置顶分别设置；兼容旧版偏好与已保存无线设备。

## 下载与使用

1. 下载并完整解压 `Qzz-Mirror-0.2.1-win-x64.zip`，保留 `qzz-mirror.exe` 旁的 `runtime` 文件夹。
2. 如果旧版本仍在运行，先右键系统托盘中的轻镜图标，选择“退出”。关闭面板只会进入托盘。
3. 双击新目录中的 `qzz-mirror.exe`，选择设备并点击“开始投屏”。首次 USB 连接需在手机上允许调试；无线连接需处于同一局域网。

支持 Windows 10 / 11 x64，需要 WebView2 Runtime；无需另配 adb。发布附件提供 ZIP 的 SHA-256 校验文件。

日常使用下载 `Qzz-Mirror-0.2.1-win-x64.zip` 即可。另附 `Qzz-Mirror-0.2.1-third-party-sources.zip`，提供本版 FFmpeg、libusb 的对应源码和上游构建资料；许可文本位于便携包内的 `third-party-licenses`。

- 0.2.1 已完成前端构建、浏览器图标及 Windows ICO 小尺寸目检；发布前重新运行的 13 项后端单元测试、17 项隔离集成检查均通过。
