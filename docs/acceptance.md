- IT-400i USB 真机：型号、硬件标识、Android 9 / API 28 识别正确；从面板启动后有实际画面，启动参数使用明确 USB serial 和 `--no-audio`；停止后该投屏子进程结束。
- 真机发现并修正 scrcpy 5 日志兼容问题：`Texture (D3D11VA): 480x800` 现可识别为画面就绪，并已有实测格式回归测试。

- 便携包：生产构建已启用 `custom-protocol`，界面嵌入主程序。ZIP 的 SHA-256、EXE 校验值和核心清单均通过；另在含中文与空格的解压目录完成 14 个运行文件的哈希及组件版本检查。
